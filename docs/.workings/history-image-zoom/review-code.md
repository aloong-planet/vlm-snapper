# 原图滚轮缩放代码审查 — 2026-09-22

范围：本轮 HistoryImagePreview 原生视口、双语提示及新增事件测试；保留前轮尚未提交的历史详情修改。

## ① 底层前提

原生 NSScrollView 的 magnification 和 centeredAt 的图像坐标锚点通过当前生产 View 实测：滚轮放大及反向恢复，指定图像点转换回窗口后偏差不超过1pt。NSImage 表示的物理像素尺寸沿用原图预览既有语义，不修改源文件。输入是已通过原记录身份/摘要验证的快照，而非新的路径读取。

## ② 可运行性

进入时默认适应；布局更新重算适应比例；手动缩放先更改原生模式再通知 SwiftUI，避免更新回调把刚得到的倍率复位到100%。按钮显式切换100%/适应。零滚动和惯性事件不转换模式。长图拖拽按当前缩放换算位移，clip限位，小图居中。关闭sheet释放本地模式，重开创建新视口。

故障逃逸面：预览缩放只改变当前视口，不改变其他记录、请求、持久化或全局事件分发；边界为自伤。未发现阻断缺陷。实测为原生响应入口，不等于物理鼠标/触控板已验收。

## ③ 安全正确性

没有全局事件监视器、AX权限新增、网络、图片路径重开或凭据访问。滚轮被预览自己的scrollWheel消耗，不调用父滚动实现。有限倍率和单次增量夹紧防止无界指数放大；图片不可用的原入口不变。未引入跨记录状态或持续后台资源。

## ④ 一致性

复用主题表面/文字颜色、既有尺寸切换按钮与关闭按钮；新增提示成对进入中英字典，无新增图标。当前渲染已核对fit/zoom两张原生整窗图，标题及操作未遮挡。spec AC-20、原型与features均描述同一交互。私有NSScrollView/NSClipView/NSImageView分别负责倍率、居中、拖拽，有明确系统边界，不扩成通用图片编辑框架。

本轮无新增改动面外字符图标发现，未做全仓图标穷举。物理设备手感、惯性、Esc与多屏沿用清单中的人工验收边界；不据此声称全feature收口。
