# Ticket 13 — 方案审查

## 备选方案

1. 继续依赖 AppKit 自动选择名称：当前单状态项通常可用，但身份由框架隐式决定。
2. 设置固定 `autosaveName`：显式、稳定、范围窄，符合用户要求。
3. 修改 macOS 私有排序偏好：能够猜测位置但没有公开契约，系统升级风险高，否决。

## 审查结论

选择方案 2。设置时机必须紧邻状态项创建，避免后续代码误以为名称可动态变化。名称不进入本地化字典，也不抽成可配置项。该方案不改变左键、右键、截图、更新提示或退出路径，没有 race、资源生命周期或敏感数据影响。

单元测试豁免成立：测试只有在暴露私有 AppKit 对象或重复生产常量时才能观察该接线，两种方式都会制造假信号。保留严格构建、现有菜单栏行为测试、全量回归和真实重启验收。
