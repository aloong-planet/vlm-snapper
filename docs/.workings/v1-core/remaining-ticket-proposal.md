## 历史筛选待确认的设计（建议，不是已批准要求）

- 布局：推荐保留类型/搜索工具栏，加“筛选”入口在其下展开同页高级筛选区；全部筛选在一个界面可见，最小窗口不裁切。不另建独立配置窗。
- 组合及撤销：推荐不同维度用 AND、每个维度单选，“全部”解除该维度，提供一次清除筛选；搜索也参与 AND。须确认清除是否包含搜索及当前 Pinned 导航。
- 选项来源：推荐从历史记录本身提取 Provider/模型/语言，而非当前 Provider 网络列表；已移除配置的历史仍可检索。模型是否随 Provider 联动、同名模型如何区分需明确。
- 目标语言：推荐明确筛选目标语言时不匹配没有目标语言的提取记录；未限定语言时两类操作都可参与。
- 日期：推荐按记录创建时间、用户当前时区的自然日解释“从/到”，界面含首尾日期；内部可换算为起始日零点至结束日下一日零点的半开区间。需确认时区变化、夏令时、空端点及开始晚于结束的显示/阻断行为。现有 SQL 下闭上开只是实现现状，不是批准依据。
- 生命周期/空态：推荐条件只在管理中心本次窗口会话保留，切到 Pinned 保持其他条件并取交集；关闭重开恢复默认。无匹配和查询失败分别显示，不把失败伪装成“无记录”；筛选掉当前详情时不得继续展示被排除项。需确认这些新增交互。
