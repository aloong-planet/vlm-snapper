# Application Edit menu prototype

This prototype answers one question: which native editing commands should VLMSnapper expose when one of its text fields or text views is focused?

The selected direction is a complete macOS Edit menu rather than a one-off Paste shortcut. Command availability is derived from the focused responder; the prototype controls at the bottom are demonstration harness UI and are not part of the product.

The focused API-key field is shown in the inline Provider page of Settings Center. It is context for testing the responder-chain Edit menu, not a separate Provider setup surface.
