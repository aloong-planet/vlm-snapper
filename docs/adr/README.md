# 架构决策记录

本目录使用 MADR minimal 定制格式记录 VLMSnapper 的架构决策。每份 ADR 的背景、备选项、决策、后果和来源均为必填内容。

状态取值为：

- `提议`：方向已定，但仍需实测或实现验证。
- `已接受（YYYY-MM-DD）`：证据已经闭环。
- `已被 ADR-XXXX 取代`：新 ADR 已替换该决定。

已接受的 ADR 只追加、不改写；需要推翻时创建新 ADR，并同步更新旧条目与本索引。这里只记录本项目中难以逆转、缺少上下文会令人费解、且源于真实取舍的架构决定，不记录一般流程或简单实现细节。
